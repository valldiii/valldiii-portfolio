01 // ABOUT ME

Membangun website dengan fondasi yang kuat, rapi, dan bertanggung jawab.

Halo! Saya Valldiii, mahasiswa aktif program studi Teknik Informatika yang memiliki minat mendalam dan fokus konsisten pada bidang pengembangan web front-end.

Di tengah pesatnya teknologi, saya meyakini bahwa website yang berkualitas lahir dari penguasaan fundamental yang kuat: HTML semantik untuk aksesibilitas dan struktur yang benar, CSS modern untuk tata letak yang luwes, serta JavaScript murni untuk interaktivitas yang gesit tanpa bloatware.

Sebagai pengembang yang terus bertumbuh, nilai utama yang saya bawa adalah kejujuran teknis, ketelitian penulisan kode, serta transparansi penuh dalam berkomunikasi dengan Anda.

02 // TECH STACK

Teknologi yang Benar-Benar Digunakan

Hanya alat dan teknologi standar web yang saya pahami, kuasai, dan terapkan secara konsisten dalam proyek nyata.

HTML5 Semantik

Fondasi

Menyusun dokumen web dengan tag semantik standar (<header>, <main>, <article>), ramah SEO, serta memenuhi standar aksesibilitas dasar.

CSS3 & Modern Layouts

Gaya & Desain

Penguasaan mendalam CSS Flexbox, CSS Grid, Custom Properties (Variables), Fluid Typography, dan transisi halus tanpa ketergantungan library luar.

Vanilla JavaScript

Interaktivitas

Manipulasi DOM, penanganan event, filter dinamis, modal interaktif, validasi formulir, dan konsumsi Web API modern tanpa framework berat.

Responsive Web Design

Mobile First

Perancangan tata letak fleksibel menggunakan media queries cerdas dan viewport units, menjamin tampilan sempurna di laptop, tablet, dan smartphone.

Git & Version Control

Alur Kerja

Pelacakan perubahan kode, branching, commit history yang rapi dan terorganisir untuk menjaga integritas proyek website Anda.

Web Performance Audit

Optimasi

Analisis waktu pemuatan, pemangkasan CSS yang tidak terpakai, dan optimasi aset visual menggunakan Chrome DevTools dan Lighthouse.
